# Official pinned prose inputs

These six files are unchanged copies of the RDF/HTML files already listed with
SHA-256 hashes in the adjacent base registries. The builder checks those hashes
before reading prose. They permit offline reproducibility and are not benchmark
inputs or reference requirements. RDF imports and HTML links are never followed.

DCAT-AP releases are from SEMICeu/DCAT-AP, commit
`4470b8ea907b7eb9ec55ab22befd1ecd2210ff32`. W3C specifications are the dated
DCAT 2 recommendation (2020-02-04) and DCAT 3 recommendation (2024-08-22).
Original source notices and attribution are retained in each file.

Definition text is copied verbatim (HTML whitespace normalised); RDF description
blocks are matched by their class-context anchors before graph merging can lose
that association. Catalogues remain drafts marked unreviewed.
