separate from benchmark source decks and evidence inputs.

The registry builder extracts class/property membership, obligations, cardinality,
ranges and usage notes from the final specification's per-class tables; vocabulary
guidance comes from §5.2 and is stored with PDF page locators. Registry output pins
the PDF checksum. The PDF is a base-profile source, not a StatDCAT evidence-deck
document; do not add it to the benchmark corpus.
