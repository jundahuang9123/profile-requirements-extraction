# EPOS-DCAT-AP: exploratory / partial

This is **not a quantitative gold benchmark**. The original requirements elicitation
corpus, stakeholder material and an independently enumerated reference set were not
recovered. A final schema or shape file cannot serve as independent upstream evidence.

The [official EPOS repository](https://github.com/epos-eu/EPOS-DCAT-AP) supplies a frozen
**v1.0.0** specification, pinned at commit
`8a6b0d4d1f04a9c14eb43bc3e73d3d6cb541fff9`, in `reference-requirements/`. Its original MIT
licence is retained in provenance. The exact original publication date is left unknown.

`exploratory/` contains a pre-profile W3C DCAT baseline and the project's public scope /
reference list, pinned separately to its current repository commit. That README includes
later 2018–2022 publications, so it is **context**, not a historical v1 raw input. Relevant
papers have citation records; publisher works are not copied without verified rights.

Both scored runtime allowlists are empty. Explore the ability to formulate grounded
requirements from licensed public infrastructure context only under a separately defined
protocol. Do not infer reference recall, or include EPOS in averages with mobility, from
the finished profile alone.

See [manifest](provenance/manifest.json), [gaps](provenance/GAPS.md), and
[methodology](../BENCHMARK-METHODOLOGY.md).
