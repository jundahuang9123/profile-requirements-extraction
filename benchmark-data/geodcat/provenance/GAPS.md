- ISO normative standard texts: copyright-restricted, citation only.
- Original working-group submissions, alignment drafts and private implementation experiences: not fully reconstructed.
- DCAT-AP 1.1 historical bytes and original INSPIRE/DCAT-AP 2014 alignment package: not recovered.
- Raw original 1089/2010 law does not include every later pre-2015 amendment. Review coverage before scoring.

Citation-only documents contribute no original source text to the runtime corpus.
These gaps affect attainable coverage and must be reported in evaluation.
